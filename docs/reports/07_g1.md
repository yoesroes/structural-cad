# Laporan G1 — Jembatan v1 → batang

**Tanggal:** 2026-10-24  
**Pohon kerja:** `cad_f5_f6/`  
**Prasyarat:** F4 (layout `src/`); F5–F6 sudah ada di pohon ini.

## Tujuan

Dari dokumen project v1 (`kind: project`) menghasilkan batang per pile sebagai `BarGroup` (`scad_engine.model`) agar rekap, tabrakan, dan (nanti) potongan bisa memakai mesin yang sudah ada.

**Cakupan v1:** elemen `bored_pile`, bentuk `R20` (lurus), `R87` (heliks), `RING`.

## Berkas

| Path | Peran |
|------|--------|
| `src/scad/shapes.py` | `build_centerline`, `cut_length_formula` (murni, tanpa impor engine) |
| `src/scad/placement.py` | `PileEnv`, `place_rebar` → daftar `Placed` (polar / linear z / single) |
| `src/scad_engine/from_v1.py` | `build_bar_groups`, `recap_pile`, `recap_group` |
| `src/scad_ui/server.py` | **GET** `/api/pile/{id}/recap`, **GET** `/api/group/{id}/recap` |
| `tests/engine/test_from_v1.py` | Acuan numerik P1 |

Arah impor tetap: `scad_ui` → `scad_engine` → `scad` (`shapes` / `placement` tidak mengimpor `scad_engine`).

## Perilaku utama

1. **Lingkungan ekspresi:** parameter efektif pile (definition → defaults → overrides), `d`, `d_of(id)`, `zone_length(id)`, `pi`; zona dari `scad.zones.resolve_zones`.
2. **Rentang batang:** gabungan `extent.zones` + `extend_start` (ke atas) / `extend_end` (ke bawah).
3. **Posisi outer / clear:** jari-jari sumbu = `D/2 − offset − d/2`; **center:** `D/2 − offset`.
4. **Arrangement:** polar (+ bundle tangensial), linear axis z (spacing), single (heliks).
5. **Issues:** `LEN_MISMATCH` (geo vs `cut_length`, tol. 0,5 mm); `RULE_SPACING` jika jarak bersih antar *lokasi* polar &lt; `settings.rules.min_clear_spacing` (pasangan dalam bundel diabaikan).
