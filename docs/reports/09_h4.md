# Laporan H4 — Kebersihan, tes, dan dokumentasi

## Berkas diubah

- `.gitignore` ditambahkan untuk artefak Python, Node, build, output, dan OS.
- `tests/ui/test_static_security.py` ditambahkan untuk traversal URL, encoded path,
  query string, dan symlink keluar direktori static.
- `tests/test_examples_valid.py` ditambahkan untuk memaksa contoh root berupa
  dokumen v1 atau fixture yang diizinkan eksplisit.
- `tests/test_schema_sync.py` ditambahkan untuk memeriksa dua salinan skema byte-identik.
- `tests/engine/test_generic.py` diarahkan ke `examples/legacy/generic_single_bar.json`.
- `examples/generic_single_bar.json` dipindahkan ke `examples/legacy/`.
- `docs/UI.md`, `docs/FILES.md`, dan `docs/ENGINE.md` diperbarui terhadap rute dan
  layout aktual.
- Laporan tahap lama dipindahkan dan dinamai ASCII berurutan di `docs/reports/`.
- `scripts/sync_schema.sh` diperbaiki agar menyalin ke `src/scad/data/`.

`PC_8400.elem.json` tetap menjadi pengecualian TODO H3 sesuai `tasks/H4_CATATAN.md`;
file itu belum memenuhi skema v1 dan tes memastikan pengecualian tersebut terlihat.

## Perintah dan hasil

- `pytest -ra` → **177 passed, 1 skipped, 5 subtests passed** dalam 19,54 detik.
- `pytest -q tests/test_examples_valid.py tests/test_schema_sync.py tests/ui/test_static_security.py` → **5 passed**.
- `node --experimental-strip-types --no-warnings --test 'web/src/**/*.test.ts'` → **26 passed, 0 failed**.
- `bash scripts/sync_schema.sh` → `OK (identik)`.
- Pemeriksaan artefak setelah pembersihan → tidak ada `__pycache__`, `.pytest_cache`,
  `*.egg-info`, `*.pyc`, atau `*.pyo`.

## Asumsi dan keputusan

- Fixture non-dokumen (`expected_zones.P1.json`, `ops_golden.json`, `pilecap.json`)
  tetap berada di `examples/` karena dipakai langsung oleh tes/mesin; daftar izinnya
  eksplisit dan dijaga oleh tes.
- `generic_single_bar.json` adalah input mesin generic legacy, bukan dokumen v1,
  sehingga dipisahkan ke `examples/legacy/`.
- Perbaikan path `scripts/sync_schema.sh` diperlukan karena layout target H2b sudah
  berpindah dari `core/scad` ke `src/scad`.

## Perbaikan lanjutan

Mutasi negatif `linear tanpa axis` pada `tools/check_examples.py` kemudian
diperbaiki: mutasi sekarang mengubah arrangement grup menjadi `pattern: linear`
dan memakai `pop("axis", None)` secara aman. Dengan demikian tooling tidak crash
dan tetap menghasilkan dokumen invalid yang memang menguji syarat `axis`.
