# T05 — Antarmuka plugin elemen + metadata bored pile dan pile cap
Baca `00_KONTEKS.md` dulu. Pakai `jsonschema`.
**Tujuan:** `core/scad/plugins/base.py` (ElementPlugin ABC, `register_plugin`, `get_plugin`, `list_plugins`), `bored_pile.py`, `pile_cap.py`, dan `__init__.py` yang mendaftarkan keduanya. HANYA metadata, belum ada geometri.
**Isi:** `bored_pile`: `type_version=1`, `params_schema()` memuat diameter, depth_below_cof, cover, cover_ref (sama dengan `BoredPileParams` di skema), `faces()` = ["outer","top","bottom","axis"], `overridable_params()` = ["depth_below_cof"], `local_frame_doc()` menjelaskan: sumbu pile di (0,0), z=0 di COF, z positif ke atas. `pile_cap`: params menurut `PileCapParams`, faces = ["top","bottom","x-","x+","y-","y+"], `overridable_params()` = [], kerangka lokal: sudut (0,0,0) di dasar, x panjang, y lebar, z ke atas. Tambahkan fungsi `validate_params(type_id, params) -> list[Issue]` yang memeriksa terhadap `params_schema()` (galat `SCHEMA`, path relatif ke `/params`). `get_plugin` tipe tak dikenal -> `KeyError` berpesan Indonesia.
**Berkas keluaran:** `core/scad/plugins/*.py`, `core/tests/test_plugins.py`.
**Uji wajib:** `list_plugins()` = ["bored_pile","pile_cap"]; params contoh `BP_D1200` lolos; tanpa `depth_below_cof` -> galat; `params_schema()` setara dengan `$defs/BoredPileParams` di skema; plugin ganda didaftarkan dua kali -> `ValueError`.
