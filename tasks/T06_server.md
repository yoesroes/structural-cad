# T06 — Server lokal (FastAPI) + OpenAPI
Baca `00_KONTEKS.md` (kontrak API) dulu.
**Tujuan:** `server/main.py` dan `server/openapi.yaml` untuk empat endpoint pada kontrak, mengikat ke 127.0.0.1 saja.
**Aturan:** kode terhadap kontrak antarmuka Python, bukan implementasi: impor `scad.validate.validate_document`, `scad.zones.resolve_zones`, `scad.io.files`. Bila modul belum ada di lingkungan, uji dengan stub yang memenuhi kontrak (letakkan di `server/tests/stubs/`, JANGAN di `core/`). `resolve`: untuk tiap grup dan pile, nilai = `definition.data.params` -> `defaults.params` -> `overrides.params`; `zone_lengths` dari `overrides`; isi `overridden` (mis. ["depth_below_cof","zone:Z2"]); galat `ZoneError` dikonversi menjadi `Issue` (error, kode dari `ZoneError.code`, path ke pile) dan pile itu `zones: []`. `file/open` dan `file/save` hanya menerima path yang berakhiran `.project.json`, `.elem.json`, atau `.shapes.json`; selain itu 400. Galat I/O -> 400 dengan pesan Indonesia. CORS hanya untuk `http://127.0.0.1:5173` dan `http://localhost:5173`.
**Berkas keluaran:** `server/main.py`, `server/openapi.yaml` (cocok dengan aplikasi), `server/tests/test_api.py`, `server/README.md` (cara menjalankan).
**Uji wajib (TestClient):** resolve `examples/P1.project.json` menghasilkan P1-2 dengan `overridden=["depth_below_cof"]` dan Z3=15000, P1-8 dengan `["depth_below_cof","zone:Z2"]` dan Z3=16000; path berekstensi salah -> 400; simpan lalu buka kembali sama.
