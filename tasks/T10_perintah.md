# T10 — Registri perintah, menu, dan parser konsol
Baca `00_KONTEKS.md` dan `web/src/types.ts` (Operation).
**Tujuan:** logika murni tanpa React di `web/src/commands/`.
**Isi:** (1) `registry.ts`: daftar perintah `{id, label, menu: string[], shortcut?, enabled(state)}` untuk menu File > Project (Baru, Buka, Simpan, Simpan Sebagai), File > File Elemen (Baru, Buka, Simpan, Simpan Sebagai), Tambahkan File Elemen ke Project, Perbarui Definisi dari File, dan menu Elemen/Tulangan/Periksa/Ekspor (cukup judul item; belum aktif). `state` = `{hasProject, dirty, hasElementFile}`. Fungsi `buildMenu(state)` mengembalikan pohon menu dengan flag `enabled`. (2) `console.ts`: `parseConsole(line, doc) -> {ok:true, op: Operation} | {ok:false, message: string}`. Sintaks tidak peka huruf besar-kecil: `SET <pile> DEPTH <mm>`, `RESET <pile> DEPTH`, `SET <pile> ZONE <idZona> <mm>`, `RESET <pile> ZONE <idZona>`. Grup dicari dari ID pile di `doc.groups[*].instances`; pile tak ada -> pesan Indonesia. Nilai harus angka > 0. (3) `apply.ts`: `applyOperation(doc, op) -> {doc, inverse: Operation | null}` murni (tidak mengubah masukan). `set_pile_depth` menulis `overrides.params.depth_below_cof`; bila nilai sama dengan default grup, hapus penimpaan (dan hapus `overrides` yang kosong). `reset_*` menghapus penimpaan. `inverse` mengembalikan keadaan semula.
**Berkas keluaran:** `web/src/commands/registry.ts`, `console.ts`, `apply.ts`, `web/src/commands/commands.test.ts`.
**Uji wajib:** `SET P1-1 DEPTH 27000` -> op benar dan hasil `applyOperation` berisi override; `SET P1-1 DEPTH 30000` (sama dengan grup) tidak meninggalkan `overrides`; `RESET P1-2 DEPTH` menghapus override P1-2; inverse dari set mengembalikan dokumen yang `toEqual` aslinya; `SET P1-99 DEPTH 1000` gagal dengan pesan; menu: tanpa project item "Simpan" nonaktif.
