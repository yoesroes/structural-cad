# T07 — Kerangka UI statis dari mockup
Baca `00_KONTEKS.md` dulu. Lihat `docs/mockup/Main.dc.html` (acuan visual) dan `web/src/types.ts` (jangan diubah).
**Tujuan:** proyek Vite + React + TypeScript di `web/` yang menampilkan layar utama sesuai mockup, dengan data statis dari `examples/P1.project.json` (impor langsung) dan hasil zona dari `examples/expected_zones.P1.json`. Tanpa backend.
**Komponen (satu berkas per komponen di `web/src/components/`):** `MenuBar` (File/Edit/Elemen/Tulangan/Periksa/Ekspor/Bantuan; menu File terbuka-tutup dengan bagian Project dan File Elemen persis seperti mockup; item belum aktif tampil nonaktif), `DocTabs`, `ProjectTree` (project -> grup -> pile; pile yang menimpa grup bertanda), `Viewport` (tab 3D/Potongan/Lembar; isi placeholder SVG sederhana), `PropertiesPanel` (parameter grup, daftar zona, daftar tulangan), `ChecksPanel` (jumlah, spasi, bentrok; data contoh tetap), `PileTable` (tabel statis; versi interaktif adalah T08), `Console` (input, riwayat; hanya menampilkan ulang masukan). `App.tsx` menyusun grid: kolom 240px / 1fr / 310px, baris bawah untuk tabel dan konsol.
**Gaya:** CSS biasa dengan variabel CSS (warna dari mockup), tanpa library komponen. Tombol berupa `<button>`, field berlabel, tabel semantik; kontras teks >= 4,5:1; dapat dioperasikan dengan keyboard (menu bisa dibuka dengan Enter/Esc).
**Berkas keluaran:** `web/package.json`, `vite.config.ts`, `tsconfig.json`, `index.html`, `web/src/main.tsx`, `App.tsx`, `components/*.tsx`, `styles.css`, `web/src/__tests__/app.test.tsx`.
**Uji wajib (vitest):** pohon menampilkan 9 pile; P1-2, P1-5, P1-8 bertanda override; menu File memuat "Baru…" "Buka…" "Simpan" untuk Project dan File Elemen; Esc menutup menu. `npm run build` berhasil.
**Jangan:** menambah backend, state global eksternal, atau fitur edit.
